# AI Agent Opportunities

## Agent 1 — Management Analyst

Read-only.

Answers operational questions using canonical queries.

## Agent 2 — Contract Monitor

Scheduled.

Checks:

- deadline proximity
- collection velocity
- cost/kg deterioration
- missing activity

Produces alerts.

## Agent 3 — Document Clerk

Reads uploaded offers/receipts and creates drafts for human review.

## Agent 4 — Finance Assistant

Drafts invoices, matches payments and highlights discrepancies.

## Agent 5 — Field Entry Assistant

Turns structured chat/voice messages into draft purchases/expenses.

## Agent safety

AI writes must pass through the same authorization, validation and audit mechanisms as normal application actions.
