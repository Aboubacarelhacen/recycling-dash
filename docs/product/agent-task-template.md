# Agent Task Template

## Context

Read:
- `idea.md`
- relevant wiki pages
- relevant ADRs

## Task

Describe the smallest vertical slice to build.

## Business behavior

Describe exact business behavior.

## Data impact

List entities/fields/migrations.

## API impact

List endpoints/actions and authorization.

## UI impact

List screens, states and user roles.

## Calculations

List formulas and authoritative source.

## Audit

List sensitive mutations and audit behavior.

## Tests

List unit/integration/e2e cases.

## Non-goals

Explicitly state what is not being built in this task.
