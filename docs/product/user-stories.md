# Product User Stories

## Owner

- As an owner, I want to see all active contracts and their health so I can focus on the exceptions.
- As an owner, I want to see projected and realized margin by contract so I know where money is being made.

## Manager

- As a manager, I want to create a contract from a client offer so procurement has a clear target.
- As a manager, I want purchases to update contract progress automatically so I do not reconcile spreadsheets.
- As a manager, I want to see remaining kg and required daily rate so I know whether the team can hit the deadline.

## Field worker

- As a field worker, I want to record a collector purchase quickly so I do not lose time in the field.
- As a field worker, I want the app to work without internet so I can continue working.
- As a field worker, I want to attach a photo so I can prove a purchase/expense happened.

## Accountant

- As an accountant, I want invoice totals calculated by the system so documents are consistent.
- As an accountant, I want to trace a client invoice to the delivery and contract.
- As an accountant, I want corrections to be auditable.

## Driver

- As a driver, I want to see my assigned deliveries and destination so I know my daily route.

## Acceptance mindset

Every story must define:

- happy path
- validation
- permissions
- failure behavior
- audit behavior
- empty state
