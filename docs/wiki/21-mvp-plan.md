# MVP Delivery Plan

## Phase 0 — discovery + foundations

- confirm current business rules
- confirm currencies/units
- confirm invoice semantics
- confirm contract/payment model
- map Excel import
- confirm receipt legal requirements

## Phase 1 — transactional core

Build:

- organization/users
- clients
- materials
- collectors
- contracts
- purchases
- expenses
- inventory movements
- basic dashboard

Goal: a manager can replace the core daily Excel workflow.

## Phase 2 — fulfillment + documents

Build:

- deliveries
- invoices
- document templates
- payment tracking
- contract workspace
- reports

Goal: a contract can be executed end-to-end in the platform.

## Phase 3 — field workflow

Build:

- mobile app
- offline queue
- photo evidence
- driver/delivery workflow
- vehicle costs

Goal: reduce office re-entry.

## Phase 4 — intelligence

Build:

- contract health alerts
- daily briefing
- exception detection
- AI Q&A
- document extraction

Goal: move from recording to decision support.

## MVP success criteria

A real user should be able to:

1. Create a client contract.
2. Record field purchases against it.
3. Record expenses.
4. See current fulfillment.
5. See inventory.
6. Deliver material.
7. Generate the client invoice/receipt.
8. See projected/actual margin.
9. Trace any key number back to transactions.
