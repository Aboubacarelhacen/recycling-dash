# Dashboard & Analytics

## Dashboard purpose

The dashboard is a management cockpit, not a wall of charts.

The first screen should answer:

> **How is the operation doing today, and where is management attention required?**

## Top KPIs

Recommended first row:

- Active contracts
- Total contract value
- Quantity collected today / period
- Total spend today / period
- Current inventory
- Projected operating margin

## Contract health board

Each active contract should show:

- client
- material
- target
- fulfilled
- remaining
- fulfillment %
- deadline
- projected margin
- health

## Today panel

- purchases
- weight
- material spend
- fuel
- transport
- food
- other expenses
- total operational spend

## Management charts

Useful first charts:

1. Quantity collected over time.
2. Spend by category.
3. Contract fulfillment.
4. Cost/kg by material.
5. Revenue vs cost.
6. Profit by contract.

Avoid charts that do not drive decisions.

## Reports

### Daily report
Operational activity.

### Weekly report
Trend + exceptions.

### Monthly report
Financial + contract summary.

## Drill-down principle

Every headline number should be explainable.

Example:

Click `$17,680 operating profit` → see the contracts and transactions behind it.
